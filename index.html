How to run & output modes

Keep index.html, styles.css, jsScripts.js, pyScripts.py, and Word Photo Log Organs - Clean.zip in one folder. Run python -m http.server 8000 in that folder and open http://localhost:8000.

Normal download is the default and builds the finished DOCX in memory before downloading it. Streaming output writes the DOCX directly to the location you select. When developing in a watched VS Code workspace, save the output outside the served folder to avoid triggering a page refresh.
